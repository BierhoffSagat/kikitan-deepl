# Changelog

All notable changes made by this fork are documented here.

## 1.2.5-deepl.9

- Added DeepL API Free and DeepL API Pro translation.
- Added secure DeepL API key storage through Windows Credential Manager.
- Restored Google Translate as a selectable translation engine.
- Added translation-engine selection to the settings screen.
- Added `byDL` and `byGgl` markers to successful VRChat translation messages.
- Added a separate application name, identifier, executable, and install location so this edition can be installed alongside upstream Kikitan.
- Added an orange visual theme to distinguish this edition from upstream Kikitan.
- Improved light and dark theme presentation.
- Added Japanese localization for the new translation settings.
- Disabled the upstream automatic-update channel for this fork.
- Added build automation for the desktop/OpenVR overlay.

## Base version

This fork is based on upstream Kikitan Translator tag `1.2.5`, commit `4120588ca9d0a5b9c7aa33effd6ecd1eecf146a7`.
